# 问题报告：新增 ItemDonationService 单元测试编译失败

- 时间：2026-04-23 21:35:21
- 阶段：最后一轮单元测试覆盖补充
- 命令：`.\mvnw.cmd test`

## 失败现象

新增 `ItemDonationServiceUnitTest` 后，测试编译阶段失败。

## 失败原因

1. `verify(donationStatusUpdateMapper).insert(any())` 命中了 MyBatis-Plus `insert(T)` 与 `insert(Collection<T>)` 两个重载，Mockito 参数类型推断不明确。
2. 测试数据使用了不存在的 `DeliveryType.SELF`，实际枚举值为 `FACE`、`EXPRESS`、`ADDRESS`、`OTHER`。

## 修改方案

1. 将 `any()` 改为显式类型 `any(DonationStatusUpdateRecord.class)`，消除重载歧义。
2. 将测试捐赠交付方式改为 `DeliveryType.FACE`。

## 回归要求

修改后重新执行完整 `.\mvnw.cmd test`，确认新增服务测试和既有 API 合同测试均通过。
