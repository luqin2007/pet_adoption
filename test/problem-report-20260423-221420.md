# 问题报告：API 第 01 组执行脚本编码解析失败

- 时间：2026-04-23 22:14:20
- 阶段：执行 `test/run-api-group-01.ps1`
- 命令：`powershell -ExecutionPolicy Bypass -File test/run-api-group-01.ps1`

## 失败现象

PowerShell 在解析脚本末尾的中文 Markdown 字符串时报错，脚本未实际执行接口请求：

```text
You must provide a value expression following the '-' operator.
Unexpected token ...
```

## 失败原因

Windows PowerShell 5 对无 BOM UTF-8 文件中的中文字符串识别异常，导致字符串内容乱码后被当作表达式解析。

## 修改方案

将执行脚本中的运行时输出与 Markdown 标题改为 ASCII 文本，避免 PowerShell 5 编码解析问题。

## 回归要求

重新执行第 01 组脚本，确认脚本能完成接口请求并生成 JSON/Markdown 结果文件。
