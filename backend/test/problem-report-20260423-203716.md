## 问题：OpenAPI 未声明 Bearer 鉴权方案

- 文件：`openapi.yaml`
- 用例：`OpenApiQualityContractTest.openApiDeclaresReusableSchemasAndBearerAuth`
- 现象：`components.securitySchemes` 缺失。
- 原因：API 文档中有登录、用户、业务管理等需要 JWT 鉴权的接口，但组件区只声明了 schemas，没有声明可复用的 `bearerAuth`。
- 影响：Swagger UI 或代码生成工具无法识别接口所需的 Bearer JWT 鉴权方式。
- 修复：在 `components` 下增加 `securitySchemes.bearerAuth`，类型为 `http`，scheme 为 `bearer`，bearerFormat 为 `JWT`。

## 后续问题：OpenAPI 未声明统一响应 Result schema

- 文件：`openapi.yaml`
- 用例：`OpenApiQualityContractTest.openApiDeclaresReusableSchemasAndBearerAuth`
- 现象：补充 `securitySchemes` 后，测试继续发现 `components.schemas.Result` 缺失。
- 原因：各接口响应内联声明了 `code/message/data` envelope，但组件区没有可复用的统一响应 schema。
- 影响：接口文档重复且代码生成工具无法复用统一响应模型。
- 修复：在 `components.schemas` 下增加 `Result` schema，定义 `code`、`message`、`data` 字段。
