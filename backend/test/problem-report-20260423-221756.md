# 问题报告：API 第 01 组脚本请求兼容性失败

- 时间：2026-04-23 22:17:56
- 阶段：执行 `test/run-api-group-01.ps1`
- 命令：`powershell -ExecutionPolicy Bypass -File test/run-api-group-01.ps1`

## 失败现象

脚本完成执行但结果显示 44 条全部失败。检查 JSON 后发现主要问题来自脚本本身：

1. 当前执行环境不支持 `Invoke-WebRequest -Form`，注册和头像上传没有发出正确表单请求。
2. 成功 JSON 响应的 `Content-Type` 读取方式不够稳健，部分请求被误记为 `Object reference not set to an instance of an object`。
3. Markdown 输出中路径列误用了转义后的 `$($r.path)`，导致结果文件展示了表达式文本。

## 失败原因

执行脚本按较新的 PowerShell `-Form` 语法编写，但当前 `powershell` 命令的参数集不支持该参数。

## 修改方案

1. 普通表单改为 `application/x-www-form-urlencoded`。
2. 文件上传改用 `curl.exe -F`。
3. 响应头读取改为安全函数。
4. Markdown 表格路径输出改为普通文本。

## 影响范围

本次失败前已创建部分临时用户和验证码数据，后续重跑使用新的时间后缀，不复用失败批次。
