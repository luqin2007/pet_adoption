# 单元测试失败问题报告 2026-04-23 20:15:16

## 执行命令

```powershell
.\mvnw.cmd test
```

## 测试结果

- 阶段：`testCompile`
- 状态：编译失败

## 问题 1：MyBatis-Plus `BaseMapper` 重载方法导致 Mockito 调用歧义

- 文件：`src/test/java/com/example/backend/service/PublicityServiceUnitTest.java`
- 现象：`insert(any())` 和 `updateById(any())` 同时匹配单对象和集合重载。
- 原因：MyBatis-Plus 4/Spring Boot 4 依赖中的 `BaseMapper` 同时存在 `insert(T)`、`insert(Collection<T>)`、`updateById(T)`、`updateById(Collection<T>)`。
- 修复：使用强类型 matcher，例如 `any(Article.class)` 和 `argThat((Article article) -> ...)`。

## 问题 2：`ArticleResponse` 没有嵌套 `author` 字段

- 文件：`src/test/java/com/example/backend/service/PublicityServiceUnitTest.java`
- 现象：调用 `response.getAuthor()` 编译失败。
- 原因：`ArticleResponse` 使用扁平字段 `authorId`、`authorName`、`authorAvatar`。
- 修复：断言 `response.getAuthorId()` 和 `response.getAuthorName()`。

## 问题 3：`ApplicationEventPublisher` 的重载方法推断为 `ApplicationEvent`

- 文件：`src/test/java/com/example/backend/service/UserServiceUnitTest.java`
- 现象：`publishEvent(argThat(...))` 的 lambda 参数被推断为 `ApplicationEvent`，无法匹配 `MailSendEvent`。
- 原因：`ApplicationEventPublisher` 同时有 `publishEvent(ApplicationEvent)` 和 `publishEvent(Object)`。
- 修复：改用 `ArgumentCaptor<Object>` 捕获事件对象后再断言类型和字段。

## 问题 4：`MailSendEvent` 字段名为 `emails`

- 文件：`src/test/java/com/example/backend/service/UserServiceUnitTest.java`
- 现象：`mail.receivers()` 不存在。
- 原因：事件 record 定义为 `MailSendEvent(Set<String> emails, String title, String content)`。
- 修复：改为 `mail.emails()`。
