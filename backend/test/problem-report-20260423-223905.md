# Problem Report 2026-04-23 22:39:05

## Scope

- API actual test group 01: Notice list endpoint.
- Failed result file: `api-test-results-01-auth-user-asset-notice-20260423223853.md`.

## Symptom

- `GET /notices?page=1&size=10` returned HTTP 500 with `No static resource notices for request '/notices'`.

## Root Cause

- Some root collection endpoints were declared only as `@*Mapping("/")`.
- OpenAPI and normal REST clients use the collection path without a trailing slash, for example `/notices`.
- Spring did not match the no-trailing-slash request and routed it into static resource handling, which then surfaced as a generic 500.

## Fix

- Updated root collection/root action mappings to declare both `""` and `"/"`:
  - `NoticeController#getNoticeList`
  - `PetController#addPet`
  - `PetController#getPets`
  - `RescueTaskController#getRescueTasks`
  - `RescueTaskController#beginRescueTask`
  - `RescueTaskController#addRescueTask`
  - `UserController#getUserList`
- Added `OpenApiControllerContractTest.rootControllerMethodsSupportPathsWithAndWithoutTrailingSlash`.

## Verification Plan

- Re-run unit tests.
- Restart the API test server.
- Re-run API group 01 with `/users` and `/notices` no-trailing-slash paths.
