# 单元测试失败问题报告 2026-04-23 20:18:49

## 执行命令

```powershell
.\mvnw.cmd test
```

## 测试结果

- 阶段：`testCompile`
- 状态：编译失败

## 问题 1：救助任务类型枚举名称错误

- 文件：`src/test/java/com/example/backend/service/RescueTaskServiceUnitTest.java`
- 现象：`RescueTaskType.STRAY` 不存在。
- 原因：项目定义的救助任务类型为 `FIND`、`MEDICAL`、`OTHER`。
- 修复：改为 `RescueTaskType.FIND`。

## 问题 2：志愿者激励类型枚举名称错误

- 文件：`src/test/java/com/example/backend/service/VolunteerServiceUnitTest.java`
- 现象：`VolunteerRewardType.BADGE` 不存在。
- 原因：项目定义的激励类型为 `MATERIAL`、`CERTIFICATE`、`POINTS`、`SERVICE_HOURS`、`CASH`、`OTHER`。
- 修复：改为 `VolunteerRewardType.CERTIFICATE`。

## 问题 3：`VolunteerRewardResponse` 无无参构造

- 文件：`src/test/java/com/example/backend/service/VolunteerServiceUnitTest.java`
- 现象：`new VolunteerRewardResponse()` 编译失败。
- 原因：DTO 仅有 Lombok `@AllArgsConstructor`。
- 修复：使用 `VolunteerRewardResponse.create(reward, volunteer, issuer)` 构造期望响应。
