# 问题报告：资源接口编译失败

- 时间：2026-04-23 21:57:30
- 阶段：新增资源文件直出接口
- 命令：`.\mvnw.cmd test`

## 失败现象

项目编译阶段失败：

```text
AssetController.java:[61,56] 未报告的异常错误 java.io.IOException; 必须对其进行捕获或声明以便抛出
```

## 失败原因

`Files.probeContentType(file)` 可能抛出 `IOException`，新增 `AssetController` 只捕获了 `MalformedURLException`，没有覆盖 MIME 探测失败的 I/O 异常。

## 修改方案

将 `IOException` 纳入捕获范围，并转换为 `ServiceException.system("exception.system.asset.read_failed", e)`，使资源接口在文件读取或类型探测失败时返回统一系统错误。

## 回归要求

重新执行完整 `.\mvnw.cmd test`，确认编译、资源接口单测和 OpenAPI 合同测试全部通过。
