## 问题：`RescueTaskStatus` 枚举初始化失败

- 文件：`src/main/java/com/example/backend/entity/property/RescueTaskStatus.java`
- 用例：`RescueTaskServiceUnitTest` 三个用例均在构造 `RescueTaskStatus.CREATED` 时失败。
- 异常：`ExceptionInInitializerError`，根因 `ClassCastException: class RescueTaskStatus not an enum`。
- 原因：枚举无参构造器中调用 `EnumSet.noneOf(RescueTaskStatus.class)`。在枚举类静态初始化期间，JDK 尚未完成该 enum 类型的初始化，`EnumSet.noneOf` 可能判定该类还不是可用 enum。
- 影响：任何首次访问 `RescueTaskStatus.CREATED` 的代码都可能触发类初始化失败，救助任务状态相关 API 无法正常运行。
- 最终修复：按 `VolunteerShiftStatus` 的实现方式，将前置状态关系移到静态 `EnumMap<RescueTaskStatus, EnumSet<RescueTaskStatus>>` 中，避免在枚举构造器中调用 `EnumSet`。
