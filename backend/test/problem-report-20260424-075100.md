## Findings

1. `BaseService` helper methods used inherited `baseMapper` directly.
   - Symptom:
     - `PET-02`, `PET-05`
     - `LOST-08`, `LOST-09`, `LOST-10`, `LOST-12`
     - `PUB-10`
   - Runtime:
     - `NullPointerException: this.baseMapper is null`
   - Impact:
     - multiple read / update flows fail even though mapper-backed `save(...)` paths still work.
   - Fix:
     - switch helper methods in `BaseService` to `getBaseMapper()`.

2. Temporary media metadata could not be stored in Redis.
   - Symptom:
     - `RESCUE-02`
     - `LOST-02`
   - Runtime:
     - `SerializationException: Cannot serialize`
   - Cause:
     - `TempFileInfo` was written through JDK serialization but did not implement `Serializable`.
   - Fix:
     - make `TempFileInfo` implement `Serializable`.

3. `pet_status_record.from` / `to` collide with MariaDB reserved keywords.
   - Symptom:
     - `PET-11`, `PET-12`
   - Runtime:
     - `BadSqlGrammarException` on insert and page query.
   - Fix:
     - quote both fields with MyBatis `@TableField`.

4. `ArticleAddRequest` validated article type against the wrong enum.
   - Symptom:
     - `PUB-01`
   - Cause:
     - request validation used `ArticleStatus.class` instead of `ArticleType.class`.
   - Fix:
     - correct validator target enum.

5. `rescue_task.approve_id` schema required a value during task creation.
   - Symptom:
     - `RESCUE-04`
   - Runtime:
     - `Field 'approve_id' doesn't have a default value`
   - Impact:
     - newly created tasks cannot stay in pre-approval state.
   - Fix:
     - make `approve_id` nullable in `init.sql`, and align live test DB before rerun.

6. Several API test failures were script-side false negatives.
   - Symptom:
     - `PET-03`, `PET-04`, `PUB-02`, `PUB-11`
     - delete calls after upload failure generated trailing-slash paths like `/.../uploads/` and `/.../media/`
   - Cause:
     - these endpoints require authentication in `SecurityConfig`;
     - missing IDs after prerequisite failures cascaded into invalid paths.
   - Fix:
     - add auth headers where required;
     - skip delete-by-name when upload did not produce a filename.
