# 问题报告：API 第 01 组脚本找不到 mysqlsh

- 时间：2026-04-23 22:15:06
- 阶段：执行 `test/run-api-group-01.ps1`
- 命令：`powershell -ExecutionPolicy Bypass -File test/run-api-group-01.ps1`

## 失败现象

脚本执行到测试账号角色初始化时失败：

```text
mysqlsh : The term 'mysqlsh' is not recognized as the name of a cmdlet...
```

## 失败原因

当前 PowerShell 子进程没有加载用户级 PATH 中的 MySQL Shell 目录，导致脚本内调用 `mysqlsh` 失败。

## 修改方案

脚本启动时重新合并 Machine/User PATH，确保可以找到已加入 PATH 的 MySQL Shell。

## 影响范围

失败前已调用部分认证接口并创建一批临时注册用户。后续重跑脚本使用新的时间后缀，不复用已创建用户。
